# Edition availability

The commercial desktop edition and the open-source build share this guide. **Commercial edition only** does not mean that every listed feature requires paid membership; the commercial app's current account allowance remains authoritative.

| Availability | Features |
|---|---|
| **Both editions** | Local tasks, Projects, To-do, Automation, Agents, Skills, Library, memory, local apps, local Recycle Bin, and user-owned model/service credentials, including provider OAuth where supported. |
| **Commercial edition only** | Orkas desktop account sign-in, membership, account credits and account-funded built-in chat, search, image, video and speech services. |
| **Commercial edition only** | Personal cloud sync, cloud storage allowances and sync conflicts; human Project collaboration, invitations, shared content and shared-to-do notifications. |
| **Commercial edition only** | Public share links for messages/files, hosted app publication and its online data, and publishing Agents/Skills through the developer marketplace. |
| **Commercial edition only** | The new-account welcome conversation, account feedback flow, official desktop automatic updates, and iOS remote control. |
| **Not in this build** | The **Orkas API Key** and the Orkas-hosted chat, search, image, video, speech, voice-input and credit-based connector services it funds. Provider/API services configured with the user's own credentials remain available and can require their own accounts, authorization and fees. |

In the open-source build, open sidebar **Settings > Models**, **Settings > Data**, or **Settings > General** for the corresponding local controls. It has no Account/Plan/credits page or personal cloud-sync settings. Local app data and the local Recycle Bin remain usable. Older builds can lack newer controls or retain earlier app restrictions; the visible screen and operation result are authoritative, not a promise that installing this guide upgrades the application.
